# NexaVoice - AI Calling Platform

## 1. Technology Stack

### Backend
* **Language & Framework:** Python 3, FastAPI
* **Server:** Uvicorn
* **Database & ORM:** PostgreSQL (with `pgvector`), SQLite (for dev), SQLAlchemy, Alembic (Migrations)
* **Real-time Communication:** WebSockets, LiveKit Server
* **AI & Machine Learning Integration:**
  * **Speech-to-Text (STT):** Deepgram
  * **Large Language Model (LLM):** Google Gemini (Flash)
  * **Text-to-Speech (TTS):** ElevenLabs, Cartesia
* **Integrations:** Salesforce (`simple-salesforce`), AWS S3 (`boto3`)
* **Security & Auth:** `bcrypt`, `python-jose`, `passlib`

### Frontend (Web Dashboard)
* **Framework:** React 19
* **Build Tool:** Vite
* **Styling:** Tailwind CSS, PostCSS
* **UI/UX:** Framer Motion (Animations), Lucide React (Icons), Recharts (Data Visualization)
* **Networking & Routing:** Axios, React Router DOM

### Mobile Application
* **Framework:** Flutter (Dart)
* **State Management:** Riverpod
* **Routing:** GoRouter
* **Networking:** Dio, HTTP, Web Socket Channel
* **Real-time Audio:** LiveKit Client (WebRTC)
* **Local Storage & Utils:** Shared Preferences, Logger, UUID

### Infrastructure & Deployment
* **Containerization:** Docker, Docker Compose
* **Cloud Provider:** AWS EC2 (Ubuntu)
* **Web Server:** Nginx (planned/configured)

## 2. Platform Workflow

The NexaVoice AI Calling Platform is designed for real estate sales, integrating an AI voice agent with Salesforce CRM. The workflow follows three main pillars:

### A. Core Communication Engine (WebRTC & In-Call Audio)
* **Connection Initiation:** The mobile or web client connects to the backend via a secure JWT WebRTC room token generated by the LiveKit service.
* **Audio Routing:** The mobile application uses `MODE_IN_COMMUNICATION` to ensure low-latency (sub-200ms) audio routing, effectively bypassing standard speakerphone limitations for cellular calls.
* **AI Processing:** 
  1. The user's audio is captured and sent to the LiveKit server.
  2. The Python LiveKit worker processes the audio using the Deepgram STT plugin.
  3. The transcribed text is sent to the Gemini LLM to generate an intelligent response based on prompt templates.
  4. The response text is converted back to audio using ElevenLabs (or Cartesia) TTS and streamed back to the client.

### B. Salesforce CRM Integration & Appointments
* **Lead Synchronization:** The backend securely authenticates with Salesforce (via OAuth2 Client Credentials) to pull new leads (`Lead` objects) into the local PostgreSQL database.
* **Call Execution & Logging:** After an AI call is completed, the backend pushes detailed call logs, full transcripts, outcomes, and audio recordings back to Salesforce custom objects (`Task` / `CallLog`).
* **Appointment Booking:** During the conversation, if a lead is interested, the AI can check calendar availability and book property site visits dynamically via dedicated REST endpoints.

### C. System Analytics & Automated Follow-Ups
* **Dashboard Analytics:** The React and Flutter dashboards display real-time metrics including call conversion rates, total call durations, outcomes, and active device statuses.
* **Background Scheduler:** A cron-based background service evaluates leads marked for follow-up and automatically re-dispatches calls according to the schedule.
* **Deployment Workflow:** The platform is packaged via Docker and deployed on an AWS EC2 instance (`t3.small` / `t3.medium`). The mobile app connects directly to the server's endpoint to enable seamless functionality.
